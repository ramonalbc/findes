# Findes

Web app (instalable en el iPhone) para planificar los fines de semana de Ramón e Irene.

- **App:** HTML + JavaScript sin compilación, publicada con GitHub Pages.
- **Datos:** Supabase (tablas `plans`, `week_notes`, `extra_days`, `members`), con acceso solo para los dos miembros.
- **Festivos:** `js/holidays.js` (nacionales, Castilla y León y Salamanca). Revisar cada otoño.
- **Esquema de base de datos:** `supabase/schema.sql`.
